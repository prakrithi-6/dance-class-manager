# Dance Class Manager

A web app for a classical dance teacher to manage students, batches,
attendance and fee payments.

## Features
- Add, edit and search students
- Batches: Junior, Senior, Pre Vidwat, Vidwat
- Mark attendance per batch per date, with a summary
- Record fee payments and see pending fees
- Password login

## Tech
Python, Streamlit, SQLite, pandas

## Run
    pip install -r requirements.txt
    py -m streamlit run app.py

The database file is created automatically on first run.
